# Project Arena — مرحله‌ی ۱: هسته‌ی قابل‌بازی

نام بازی موقت است و از `GAME_NAME` در فایل `.env` تغییر می‌کند.
نبرد یک‌به‌یک ۳ دقیقه‌ای، دو مسیر، رودخانه و دو پل، سه برج برای هر بازیکن، اکسیر، دسته‌ی ۸ کارتی با دست ۴ کارتی.
همه‌ی منطق نبرد روی سرور اجرا می‌شود و مرورگر فقط نمایش می‌دهد و درخواست می‌فرستد.

## نیازمندی‌ها
- Node.js نسخه‌ی ۲۰ یا بالاتر (روی ۲۲ آزموده شده)

## نصب و اجرا
```bash
cd project-arena
npm install
cp .env.example .env      # در ویندوز: copy .env.example .env
npm start                  # یا برای توسعه: npm run dev
```
سپس `http://localhost:3000` را باز کنید. برای دیدن نبرد آنلاین یا دوستانه، یک پنجره‌ی ناشناس یا مرورگر دوم باز کنید.
برای آزمایش روی موبایل، گوشی را به همان شبکه وصل کنید و `http://<IP-کامپیوتر>:3000` را باز کنید.

## آزمایش
```bash
npm test
```
- `tests/battle.test.js`: قوانین نبرد (اکسیر، استقرار، هدف‌گیری زمینی/هوایی، پل‌ها، پایان بازی، قطع اتصال).
- `tests/net.test.js`: مسابقه‌یابی، اتاق دوستانه، تمرین، اتصال مجدد (با سوکت جعلی).
- `tests/geometry.test.js`: هندسه‌ی نمایش.
- `tests/socket.integration.test.js`: سرور واقعی با Socket.IO؛ فقط بعد از `npm install` اجرا می‌شود.

### آزمایش دستی (چک‌لیست)
1. ورود با نام دلخواه ← صفحه‌ی خانه.
2. «تمرین با هوش مصنوعی» ← انتخاب سطح ← نبرد شروع می‌شود.
3. یک کارت را انتخاب کنید؛ ناحیه‌ی سبز (مجاز) و قرمز (ممنوع) دیده می‌شود. روی میدان بزنید، یا کارت را بکشید و رها کنید.
4. اکسیر باید کم شود و کارت بعدی وارد دست شود. با اکسیر کم، کارت خاکستری است و درخواست رد می‌شود.
5. واحدهای زمینی فقط از پل‌ها رد می‌شوند؛ هوایی‌ها از روی رودخانه می‌روند.
6. نابودی برج اصلی ← پایان فوری. پایان زمان ← برنده بر اساس تعداد برج‌های نابودشده، یا مساوی.
7. «خروج» ← تأیید ← باخت. بستن تب بدون خروج ← ۳۰ ثانیه مهلت اتصال مجدد.
8. «نبرد دوستانه» ← ساخت اتاق ← کد را در پنجره‌ی دوم وارد کنید.
9. «نبرد آنلاین» در دو پنجره ← جفت‌شدن خودکار.

## افزودن چیز جدید
- **کارت:** یک آبجکت به `CARDS` در `shared/cards.js` اضافه کنید (فیلد `abilities` برای توانایی‌های آینده رزرو است). دسته باید دقیقاً ۸ کارت یکتا باشد.
- **قانون یا رویداد ویژه:** `Battle` پارامتر `rules` را می‌گیرد و روی `BATTLE` در `shared/config.js` override می‌کند (سرعت اکسیر، زمان نبرد، برنامه‌ی افزایش اکسیر).
- **آرنا:** هندسه در `ARENA` است؛ رندرر از همان می‌خواند.
- **زبان:** فایل `public/js/locales/en.js` مشابه `fa.js` بسازید و در `i18n.js` ثبت کنید.
- **تصویر/صدا:** در حال حاضر همه‌چیز placeholder است (اموجی و شکل‌های Canvas). فایل را زیر `public/assets/` بگذارید و در `public/js/assets.js` ثبت کنید؛ مسیر ناموجود ثبت نکنید.

## آنچه در مرحله‌ی ۱ پیاده‌سازی شده
نبرد کامل با قوانین بالا، هوش مصنوعی قانون‌محور (سه سطح)، مسابقه‌یابی ساده‌ی آنلاین، نبرد دوستانه با کد اتاق، حساب مهمان، قطع/اتصال مجدد ۳۰ ثانیه‌ای، پیام‌های سریع با محدودیت نرخ، انتخاب دسته‌ی ۸ کارتی، رابط فارسی RTL و موبایل‌محور، حالت کاهش جلوه‌ها.

## لودینگ فیلم و منوی جدید

- **لودینگ اول:** فیلم `public/assets/video/loading.mp4` (و نسخه‌ی `loading.webm` برای مرورگرهایی که H.264 ندارند) با صدای خودش پخش می‌شود. نوار پایین از ۱ تا ۱۰۰ پر می‌شود و بعد از پر شدن، بازی باز می‌شود. درصد واقعی است: کمینه‌ی «پیشرفت پخش فیلم» و «کارهای واقعی بارگذاری» (تصاویر منو، فونت، آماده‌شدن اولین صفحه). کد: `public/js/splash.js`.
- **صدای فیلم:** اگر مرورگر پخش خودکار با صدا را ببندد (موبایل‌ها معمولاً می‌بندند)، فیلم بی‌صدا شروع می‌شود و دکمه‌ی «برای پخش صدا لمس کنید» نشان داده می‌شود؛ اولین لمس صدا را روشن می‌کند. این محدودیت مرورگر است، نه خطای بازی.
- **موسیقی داخل بازی:** هنوز فایلی نیست. فایل را با نام `loading.mp3` در `public/assets/audio/` بگذارید (یا `MUSIC_SRC` را در `public/js/audio.js` عوض کنید). تا وقتی فایل نیست، هیچ صدایی پخش نمی‌شود و دکمه‌ی صدا در تنظیمات نشان داده نمی‌شود. موسیقی فقط بعد از پایان فیلم شروع می‌شود تا با صدای فیلم قاطی نشود.
- **تصاویر منو** (`public/assets/art/`): جزیره، کارت‌ها، معجون و قهرمان؛ همان تصاویری که فرستادید، بهینه‌شده (webp). پس‌زمینه‌ی سفید معجون برای شفاف‌شدن حذف شده است.
- **منوی اصلی:** سه دکمه‌ی گرد دور جزیره (تمرین، کارت‌ها، دوستانه)، دکمه‌ی بزرگ نبرد، سکوی دسته‌ی فعلی، ناوبری پایین با دکمه‌ی برجسته‌ی وسط، و تنظیمات (دکمه‌ی ☰ بالای بنر).

## آنچه هنوز پیاده‌سازی نشده است (به‌صراحت)

- روی منو، این بخش‌ها فقط جایگاه هستند و عدد ساختگی ندارند (با لمس پیام «هنوز پیاده‌سازی نشده» می‌آید): سطح، سکه، جواهر، جام، لیگ فصل، صندوق‌ها، فروشگاه، رتبه‌بندی و اخبار. کاشی‌های رویداد ساخته نشد چون رویدادی در بازی وجود ندارد.
- **PostgreSQL و حساب دائمی:** نشست مهمان‌ها فقط در حافظه‌ی سرور است و با ریست سرور از بین می‌رود. هیچ داده‌ای در دیتابیس ذخیره نمی‌شود و مهاجرتی وجود ندارد.
- جام، آرنا، سکه، صندوق، سطح و ارتقای کارت، فروشگاه، مأموریت، دستاورد، فصل، کلن، دوستان، رویدادها، اعلان‌ها، بازپخش و تماشا.
- صدا و موسیقی، آموزش تعاملی، صفحه‌ی تنظیمات کامل (فقط «کاهش جلوه‌ها» در خانه هست)، دو آرنای گرافیکی.
- تصویر اختصاصی کارت‌ها و واحدها (placeholder اموجی).
- ثبت نتیجه روی سرور برای پاداش/جام وجود ندارد؛ صفحه‌ی نتیجه فقط آمار نبرد را نشان می‌دهد.

## نکات امنیتی فعلی
سرور اکسیر، هزینه، مالکیت کارت در دسته، محل استقرار و نتیجه را اعتبارسنجی می‌کند. ورودی سوکت‌ها محدودیت نرخ و محدودیت اندازه دارد، سربرگ‌های CSP و `nosniff` فعال‌اند و ساخت حساب مهمان برای هر IP محدود است. `.env` در `.gitignore` است.
